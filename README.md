# le titre : Semaine 9 - Jour 2 - Conception et normalisation

une clé étrangère est la clé primaire d'une classe se retrouvant dans une autre classe

les relations :

- 1:1 : l'enregistrement d'une table représente l'enregenstrement d'une et une seule autre table
- 1:N : l'enregistrement d'une table représente l'enregenstrement d'une ou plusieurs autres tables
- N:N : l'enregistrement d'une table représente l'enregenstrement de plusieurs autres tables

la normalisation sert à structure les données afin d'éviter la redondance et les erreurs
